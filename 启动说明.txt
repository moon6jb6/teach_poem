天阙诗都·越长安——上国诗章，长安之上（内部名：越长安）
================================================
提交版运行副本（run-submit）启动说明
================================================

一、运行环境
- 操作系统：Windows 10 / 11（已在 Windows 上验证）
- 浏览器：Chrome 102+ / Edge 102+（需支持 WebGL2 与 ES Module importmap）
- Python 3（仅用于起本地静态服务，作品本身是纯前端）
- 本版本已把 three.js 0.160.0、gsap 3.12.5、书法背景图全部本地化到 vendor\ 目录，
  **断网也能完整运行**（已用 Playwright 离线模式实测：页面/three/gsap/场景/剧情对话均正常）。

二、启动方式（二选一）
方式 A（推荐）：双击 start.bat
  浏览器会自动打开 http://127.0.0.1:8080/3Dprogram_3.1.html

方式 B：命令行
  1) 在本目录（run-submit）打开终端
  2) 执行：python serve.py 8080
     （若本机 Python 较新也可用：python -m http.server 8080）
  3) 浏览器访问：http://127.0.0.1:8080/3Dprogram_3.1.html
  注意：必须先起本地服务再打开页面；直接双击 HTML 文件（file://）会因浏览器
  ES Module / CORS 限制而白屏。

三、操作说明
- 场景选择：首页为星空式场景选择界面，点击星芒按钮选择「长安三万里·朱雀大街」或「长安城西」
- 剧情引入：进入场景前为竖排书法打字机动画（按剧本逐字显示），点击任意位置可跳过当前页
- 第一人称漫游：点击画面锁定鼠标；W/A/S/D 前后左右移动；鼠标移动转动视角；
  Shift 下蹲/减速；单击空格跳跃；**双击空格切换飞行模式**（飞行中空格上升、Shift 下降）
- 场景交互：**右键**点击画面中央准星对准的建筑/人物，弹出剧情对白与分支选项
- 剧情分支：对话中点击选项（1..N）推进剧情，人物会随选项切换动画状态（如吟诵、行走、倚坐）
- 智能对话（可选）：部分人物（储光羲、岑参、王维）支持自由输入提问，需要另外启动
  api_backend.ipynb 中的 Python Flask 后端（默认 http://127.0.0.1:5000/api/chat_text，
  需自备火山方舟 Ark API Key，提交版已抹除硬编码 Key）。未启动后端时输入提问会提示
  「连接服务器失败」，不影响 3D 漫游、剧情推进、选项分支等全部主要功能（已实测）。

四、加载耗时（本机实测：Chrome + RTX 5070 + 本地线程化 http.server）
- 场景选择界面：约 1—2 秒
- 书法打字机 + 场景切换：约 3—5 秒
- 3D 模型加载：场景共引用 61 个 GLB（总计约 3.29 GB），首次进入单个场景需读取
  数百 MB 模型，本地服务下约 **30—60 秒**逐步加载完成（实测朱雀大街约 58 s、
  长安城西约 33 s）；第二、三次进入因系统文件缓存会明显加快。
  加载过程中先出现地面与天空，建筑按加载完成顺序逐个出现，属正常现象。

七、若 start.bat 闪退怎么办（中文计算机名 / 老 Python 兜底）
- 现象：双击 start.bat 后窗口一闪而过、浏览器打不开页面。原因通常是电脑名含中文时，
  老版本 Python（<=3.8）执行 python -m http.server 会在 socket.getfqdn 处报
  UnicodeDecodeError 直接退出。本包已内置兜底服务脚本 serve.py（补一行 getfqdn），
  start.bat 会优先调用它，失败再回退 python -m http.server 8080。
- 若仍闪退，请在本目录（01 作品及成果文件）打开命令行，手动执行：
      python serve.py 8080
  或（较新 Python）：
      python -m http.server 8080
  然后用浏览器打开 http://127.0.0.1:8080/3Dprogram_3.1.html 。
- 如本机未安装 Python，可改用 VS Code Live Server / 任何静态文件服务器，
  指向本目录即可（同样必须通过 http:// 访问）。
