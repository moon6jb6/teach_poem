# 天阙诗都 · 越长安 —— 上国诗章，长安之上

> **Celestial Capital of Verse · Yue Chang'an**
> 一个用 Three.js 构建的盛唐长安 3D 沉浸式唐诗教学实验作品。
> 2026 年第十四届全国大学生数字媒体科技作品及创意竞赛 · 自主选题（七）智慧教育与科普创作类 · 参赛作品

玩家以第一人称走进开元二十四年的长安：朱雀大街、春明门、东市旅舍、城西槐院。
六位可对话人物（岑参、储光羲、王维、胡商、卖花女 + 二十五处「长安物语」旁白），
约 7400 字剧情文本，配合「知人论世」的教学设计——从「读懂诗句」到「悟懂诗心」。

## 一、这是什么

作品把唐诗放回它发生的空间里。开元二十四年（736），张九龄罢相、李林甫专权，盛唐由盛转衰。
两个人站在这个节点上：

- **岑参**（20 岁），嵩山十年，四次献书被退回，坐在东市旅舍窗前写下《东归晚次潼关怀古》；
- **储光羲**（30 岁），进士及第已十年，官拜监察御史，在城西槐院读江南来信，写下《长安道》。

一个在门外求入，一个在门内思归。学生走进长安，走到诗人面前，右键对话，
问家世、问献书、问去留；诗句、时代、处境在对话里一点点对上。
可选的 AI 自由提问（需自备大模型 API Key）作为课后追问入口，固定剧情分支保证课堂节奏。

**当前内容规模**：6 类可对话人物 / 47 个对话节点 / 约 7,400 字对话文本 / 25 处物件旁白 / 2 处主场景。

## 二、快速开始

### 1. 克隆仓库

```bash
git clone https://github.com/moon6jb6/teach_poem.git
cd teach_poem
```

### 2. 准备 3D 资产（必须，仓库不含）

仓库**不含** 3D 模型与贴图（`3dmod_and_pic/`，约 3.3 GB，61 个 GLB）。原因：体积超过 Git 仓库建议上限。
请把资产包解压到本项目根目录，使目录结构为：

```
teach_poem/
├─ 3Dprogram_3.1.html      # 主程序（入口）
├─ book.js                 # 全部场景/剧情/人物/对话数据
├─ vendor/                 # three.js 0.160 + GSAP（已本地化，可断网）
├─ ui/dialogue/            # 对话卡片素材（13 张，已入库）
├─ api_backend.ipynb       # 可选：AI 对话后端（自备 Key）
├─ serve.py                # 本地静态服务器（兼容中文计算机名 + 老版本 Python）
├─ start.bat               # Windows 一键启动（端口 8080）
└─ 3dmod_and_pic/          # ← 需自行放入（模型 + 贴图 + 视频）
   ├─ mod/                 # 61 个 .glb
   └─ pic/                 # 贴图与演示视频
```

### 3. 启动（Windows 推荐）

双击 **`start.bat`**（自动起本地服务并打开浏览器）：

```
http://127.0.0.1:8080/3Dprogram_3.1.html
```

或命令行：

```bash
python serve.py 8080
# 打开 http://127.0.0.1:8080/3Dprogram_3.1.html
```

> ⚠️ 必须通过本地 HTTP 服务访问。直接双击 `3Dprogram_3.1.html`（`file://`）会因浏览器 ES Module / CORS 限制白屏。
>
> `serve.py` 已兼容「中文计算机名 + Python ≤ 3.8」环境下 `http.server` 崩溃的问题；若 `serve.py` 不可用，回退 `python -m http.server 8080`。

### 4. 操作

| 操作 | 按键 |
|---|---|
| 移动 | `W` `A` `S` `D` |
| 转视角 | 鼠标（先点击画面锁定指针） |
| 跳跃 / 飞行 | 空格 / 双击空格切换飞行 |
| 交互（对诗人、城门、器物） | **右键** |
| 对话选项 | 鼠标点击 |

首页为场景选择（朱雀大街 / 长安城西），进入前有竖排书法打字机动画，点击可跳过。

### 5. 可选：AI 自由对话

```bash
# 用 Jupyter 打开 api_backend.ipynb，把 YOUR_ARK_API_KEY 换成自己的火山方舟(豆包) Key 后运行
# Flask 默认起在 http://127.0.0.1:5000
```

不启动后端时，全部漫游、固定剧情与分支对话照常可用（AI 自由提问不可用）。

## 三、技术栈

- **前端**：纯 HTML + JavaScript（ES Module），[Three.js 0.160](https://threejs.org/) 实时渲染 + GSAP 动画；无构建步骤、无需插件，可断网运行
- **内容**：`book.js` 以 JSON 结构描述场景、人物、动作、对话树与关卡（新增一处场景/人物只需补配置与模型）
- **资产**：61 个 GLB（Blender 整理导出；部分角色由 Meshy AI 生成初版后人工调整），贴图与演示视频
- **可选后端**：Python + Flask + 火山方舟大模型接口（AI 自由提问）
- **对话 UI**：绢本卡片 + 鎏金细框 + 朱红印章 + 竖排名牌 + 笺纸选项条（素材由本地 SDXL-Lightning 生成，见 `ui/dialogue/`）

## 六、教学设计与研究价值

- **空间即教材**：把「登关城望」「西行一千里」这类空间经验做成可步行验证的 3D 场景；
- **知人论世可操作化**：诗人 NPC 的分支对话以诗作、生平与时代为据，先见人、再读诗；
- **双视角对照**：岑参「入世」与储光羲「处世」两条动线，同一座长安城的两种处境；
- **数据驱动**：`book.js` 配置化，新增场景/人物不改程序，便于课程定制与二次开发。
