## 一、评委直接打开（最短路径，三步）

交付形态是一个静态网页目录。解压材料包后进入 `01_作品及成果文件/`，目录里应有：`3Dprogram_3.1.html`（主程序）、`book.js`（关卡与剧情数据）、`vendor/`（本地库）、`3dmod_and_pic/`（模型与素材，`mod/` 为 GLB 模型、`pic/` 为图片与视频）、`api_backend.ipynb`（可选 AI 对话后端）、`start.bat`（一键启动）、`启动说明.txt`。

1. 进入 `01_作品及成果文件/` 目录。
2. **双击 `start.bat`**。脚本会在本目录起本地静态服务（默认 8080 端口），并自动用默认浏览器打开页面。
3. 页面地址：`http://127.0.0.1:8080/3Dprogram_3.1.html`。看到「星空式场景选择界面」即启动成功。

> **前提**：`start.bat` 需要机器上装有 Python 3（`python --version` 能输出版本号）。没有 Python 时，请按第二节用手动方式或 VS Code Live Server 打开；直接双击 `3Dprogram_3.1.html` 不行。

**为什么不能双击 HTML**：页面用 ES Module 加载脚本，并要读取本地的 GLB 模型、贴图与视频。`file://` 协议下浏览器会拦截这类本地资源请求，表现为白屏或一直加载。这是浏览器的安全限制，不是作品故障。

**进入后的正确流程**：

1. 场景选择界面：点击两个星芒按钮之一——「长安三万里·朱雀大街」或「长安城西」。
2. 剧情引入：竖排书法打字机动画逐字显示剧情，**点击画面任意位置可跳过**。
3. 进入 3D 场景后，先点击一次画面锁定鼠标，然后操作：

| 操作 | 键位 / 方式 |
|---|---|
| 前后左右移动 | `W` `A` `S` `D` |
| 转动视角 | 移动鼠标 |
| 跳跃 | 单击 `空格` |
| 飞行模式开关 | 双击 `空格`（飞行中 `空格` 上升、`Shift` 下降） |
| 下蹲 / 减速 | `Shift` |
| 与建筑、人物交互 | **右键点击**准星对准的目标，弹出对白与分支选项 |
| 推进剧情 | 鼠标点击对话选项（选项编号 1、2、3…） |
| 解除鼠标锁定 | `Esc` |

**跑起来了的三个检查点**：① 能看到星空场景选择界面；② 进入后能看到街市、建筑与地面；③ 右键点击场景里的诗人，能弹出对话窗口。

## 二、本地起服务（照做即可）

### 2.1 方式 A：双击 `start.bat`（Windows，推荐）

脚本内容等价于「在本目录执行 `python -m http.server 8080` 并打开浏览器」。如果双击后窗口一闪而过，说明没有装 Python，改用 2.2 或 2.3。

### 2.2 方式 B：手动起服务（Windows）

在 `01_作品及成果文件/` 目录打开 PowerShell 或命令提示符：

```bat
cd /d "解压目录\01_作品及成果文件"
python -m http.server 8080
```

看到 `Serving HTTP on 0.0.0.0 port 8080` 后，浏览器访问：

```
http://127.0.0.1:8080/3Dprogram_3.1.html
```

若提示找不到 `python`，把命令换成 `py -3 -m http.server 8080`。

### 2.3 方式 C：VS Code Live Server（图形化，适合不熟悉命令行）

1. VS Code 安装扩展「Live Server」。
2. 用 VS Code 打开 `01_作品及成果文件` 文件夹。
3. 右键 `3Dprogram_3.1.html`，选择「Open with Live Server」。
4. 浏览器自动打开（地址形如 `http://127.0.0.1:5500/3Dprogram_3.1.html`）。

### 2.4 macOS / Linux

```bash
cd "解压目录/01_作品及成果文件"
python3 -m http.server 8080
```

浏览器访问 `http://127.0.0.1:8080/3Dprogram_3.1.html`。（`start.bat` 仅适用于 Windows。）

### 2.5 成功判据与排错

| 现象 | 原因与处理 |
|---|---|
| 白屏、控制台报 `CORS` / `Failed to load module` | 用了 `file://` 双击打开；改成本地服务方式 |
| 404 / 找不到 `token` 或页面空白 | 启动服务的目录不对：必须在含 `3Dprogram_3.1.html` 的目录里启动；地址要带 `/3Dprogram_3.1.html` |
| `Address already in use`（端口被占用） | 换一个端口，如 `8081`，地址同步改端口 |
| 进入场景后先只有地面和天空，建筑一块块出现 | 正常：模型按加载完成顺序逐个上屏（见第三节加载耗时） |
| 鼠标不能转视角 | 先点击一次画面锁定鼠标；按 `Esc` 会解除，再点一次恢复 |
| 想关闭服务 | 在命令行窗口按 `Ctrl + C`，或关掉 `start.bat` 的窗口 |

### 2.6 可选：开启 AI 自由对话（评审不开启也能完整演示）

1. 用 Jupyter Notebook 打开 `api_backend.ipynb`，把其中 `YOUR_ARK_API_KEY` 替换为可用的方舟（豆包）接口凭据，再运行代码单元；Flask 会起在 `http://127.0.0.1:5000`。
2. 需要外部大模型服务凭据与网络（凭据不随评审材料公开，提交版 Notebook 已抹除真实 Key）。回答由外部大模型生成，并在角色提示词中按角色软约束为 30—50 字（岑参 30，储光羲、王维、胡商 50，卖花女 40）；这是提示词软约束，不是后端硬截断。
3. 页面中的请求地址固定为 `http://127.0.0.1:5000/api/chat_text`，后端需与页面同机运行。
4. 未启动后端时，点击对话输入框提问会提示「连接服务器失败」；固定剧情对话不受影响，课堂流程与评审演示完整可走。

## 三、浏览器与硬件要求

| 项目 | 要求 / 建议 | 说明 |
|---|---|---|
| 浏览器 | Chrome / Edge 102+，建议更新到最近两年版本 | 需支持 WebGL 2 与 ES Module importmap；其他内核未实测 |
| 显示分辨率 | 推荐 1920×1080（16:9） | 投影与录屏按此设置；更低分辨率可运行但视野变小 |
| 显卡 | 需要 WebGL 2；独立显卡与集成显卡均可运行 | 本机实测（RTX 5070 Laptop）：长安城西约 64 fps，朱雀大街全量模型约 9—36 fps；其他机型未逐一压测 |
| 内存 / 磁盘 | 提交包约 3.29 GiB / 3.53 GB（其中 3D 资产约 3.28 GiB）；精简包约 2 GB（剔除未引用模型）；建议预留 ≥4 GB 磁盘 | 建议放本地 SSD；机械硬盘加载明显更慢 |
| 网络 | three.js / GSAP 已本地化到 `vendor\`（提交版）；**提交版已实测：断网可进入场景、可走固定剧情对话（2026-10-22 网络层阻断实测）** | 仅「AI 自由对话」需要外部网络 |
| 操作系统 | Windows 10 / 11（已在 Windows 上验证） | macOS / Linux 未实测；`start.bat` 仅 Windows |
| 输入设备 | 键盘 + 鼠标 | `WASD` 移动、鼠标转视角、右键交互；触摸屏不支持 |
| 其他 | 允许浏览器播放视频 | 剧情引入与场景视频默认静音；如被拦截，点击画面继续 |

**加载耗时（本机实测：Chrome + RTX 5070，本地静态服务）**：

| 阶段 | 实测耗时 |
|---|---|
| 场景选择界面 | 约 1.2 秒 |
| 竖排书法打字机出现 / 3D 场景首帧 | < 0.5 秒 / 1—3 秒 |
| 3D 模型首次加载（单场景） | 「朱雀大街」约 58 秒（11 个模型 / 约 1.29 GB）；「长安城西」约 33 秒（5 个模型 / 约 0.85 GB）；建筑由近及远逐个出现属正常现象 |

以上为本机实测（Chrome + RTX 5070 Laptop，本地静态服务）；机械硬盘或低配置机器会更慢。建议演示前先完整进入一次场景（预热磁盘缓存），第二次进入会明显加快。

## 四、已知限制

1. **资产体积大、首次加载慢**：场景引用约 60 个 GLB（3D 资产约 3.28 GiB），单场景首次进入需读入数百 MB 模型，实测「朱雀大街」约 58 秒、「长安城西」约 33 秒；加载期间先出现地面与天空、建筑逐个出现是正常现象，不是卡死，请不要反复刷新。
2. **必须通过本地服务打开**：直接双击 HTML 会因浏览器安全限制白屏（见第一节），需按第二节起服务（推荐 `start.bat`）。
3. **AI 自由对话依赖外部接口与网络**：需要另起 Python 后端并填入自己的接口凭据；不开后端时 AI 提问不可用，但固定剧情对话完整可用，课堂流程与评审演示不受影响。
4. **移动端未适配**：手机、平板无法操作（需要键盘与鼠标），作品以桌面、机房与投影环境为主。
5. **场景与内容范围**：交付版为两处主场景（长安东市/朱雀大街、长安城西）与两位诗人的对话线；江南场景、酒肆/官署/客栈的部分内部细节尚未完成；部分材质为贴图，近看细节有限。
6. **没有环境音效与人物配音**：本版本未实现背景音效与角色语音，剧情引入与场景视频默认静音；与配套教案中设想的音效环节有差距，特此说明。
7. **性能差异明显**：本机（RTX 5070 Laptop）实测长安城西约 64 fps、朱雀大街全量模型约 9—36 fps；低配置机器可能更慢，未做全机型压测。
8. **浏览器兼容范围窄**：只对 Chromium 内核做过运行验证，其他内核未实测。
9. **断网实测边界**：断网可运行性已于 2026-10-22 实测通过（网络层只放行本地服务），实测环境为本机 Chromium 内核浏览器；其他浏览器未逐个复测。

## 五、常见问题

**Q1：双击 `3Dprogram_3.1.html` 是白屏，是不是作品坏了？**
不是。请双击 `start.bat`（需 Python 3）或按第二节起本地服务，再访问 `http://127.0.0.1:8080/3Dprogram_3.1.html`。

**Q2：进入后只有地面和天空，建筑还没出来？**
模型正在加载（约 30—120 秒），请等一会儿；不要反复刷新。加载顺序是从地面、天空到建筑逐个出现。

**Q3：鼠标不能转视角？**
先点击一下画面锁定鼠标；按 `Esc` 可以解除锁定，再点一次恢复。

**Q4：点了诗人没有 AI 回复？**
AI 自由对话需要另起 Python 后端并联网（见 2.6）；不启动时，诗人仍按固定剧情回答，这是设计内的降级，不是故障。

**Q5：为什么只有两处主场景？**
交付版聚焦「知人论世」双视角教学：东市（岑参）与城西（储光羲）两处主场景对应两首诗的课堂动线，其余为后续扩展内容。

**Q6：为什么没有声音？**
本版本未加入环境音效与配音，剧情视频默认静音（见第四节第 6 条）。
