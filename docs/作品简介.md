## 一、短版（报名系统用，≤300 字）

《天阙诗都·越长安——上国诗章，长安之上》是一个面向古诗文课堂的纯网页 3D 教学作品。打开浏览器，学生以第一人称走进开元二十四年的长安：朱雀大街、春明门、东市旅舍、城西槐院。二十岁的岑参在东市旅舍临窗写下《东归晚次潼关怀古》，三十岁的储光羲在城西槐树下读江南来信、写下《长安道》。两人同写长安，学生走近诗人、右键对话、选择问题，把「知人论世」走一遍，再回到诗句。作品用 HTML + Three.js 实现，book.js 配置化关卡，含约 60 个 GLB 场景资产与可选 AI 对话；无需插件，提交版外部依赖已本地化。

## 二、长版（评审材料用，800—1200 字）

**作品定位。** 《天阙诗都·越长安——上国诗章，长安之上》是一个纯网页的 3D 沉浸式唐诗教学作品。作品以开元二十四年（736）的长安为课堂：学生以第一人称走进朱雀大街、春明门、东市旅舍与城西槐院，在空间里完成「知人论世」，从读懂诗句走到悟懂诗心。作品把诗人、时代与文本放回同一个空间，让学生先见到人，再读诗。教学对象为中学古诗文课堂、高校中文与历史类通识课，以及自学者。

**主要创新。** 一、把「知人论世」做成可走的空间动线：东市（岑参，入世）与城西（储光羲，处世）两处场景对照，用脚步完成两位诗人处境的比较。二、诗人 NPC 的分支对话以诗作与生平为据：问家族、问嵩山十年、问投诗锦匣、问河朔之行，储光羲这边问江南来信、问为何不辞官；另设王维、胡商、卖花女三条长安众生支线，回答都能落回诗句与史料，不是百科式问答。三、双通道对话：固定剧情保证课堂节奏；AI 自由提问为可选通道（需另开 Python 后端、自备 API Key），回答由外部大模型生成，角色提示词中按角色软约束 30—50 字；不开启后端时仍走固定剧情。四、配置化关卡：book.js 用 JSON 描述场景、人物、动作与分支，新增一处场景或一位诗人只需补配置和模型，便于教师二次开发与课程定制。

**实现方法。** 作品用 HTML + Three.js（0.160.0）搭建，约 60 个 GLB 场景资产（提交包约 3.29 GiB / 3.53 GB；3D 资产约 3.28 GiB）；资产由团队用 Meshy AI 等工具生成并结合素材补充，经人工筛选调整后在 Blender 中整理导出；场景布局、关卡、交互与程序由团队完成。第一人称漫游 WASD + 鼠标，交互用射线检测、右键触发；诗句、对话与剧情页由 book.js 的 JSON 配置驱动。提交包已本地化 three.js 与 GSAP（vendor\），提交版已实测断网可进入场景、可走固定剧情；首次加载需读入 GLB 资产，建议放 SSD。

**完成程度。** 已完成两处主场景、两位诗人主线与王维、胡商、卖花女三条支线对话（人物对话合计约 5000 字），含开场视频、书法打字机剧情页、场景选择与分支对话，配有一课时（45 分钟）教案。仍在完善：江南场景未做；酒肆、官署、客栈的部分内部细节待补；移动端未适配；AI 对话依赖外部模型接口与网络（需自备接口凭据）。

**学生贡献。** 作品由 5 名本科生共同完成，分工覆盖剧本与教学内容、三维场景与美术、程序与交互实现、测试与提交材料。场景布局、对话脚本与关卡配置由团队逐条对照诗作与教案确定；AI 只用于部分素材生成与代码辅助，人工筛选与修改情况见《AI 工具使用情况说明》。

**应用价值。** 可用于中学语文课堂与高校中文、历史类通识课的分层教学，也可用于图书馆、纪念馆的唐诗主题展陈；关卡数据与渲染逻辑分离，新增内容只需补配置和模型，便于课程定制与持续迭代。
