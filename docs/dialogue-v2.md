## 10. 遗留风险与待办（交 Lead / project-runner）

1. **王维模型外观与史实年龄的张力**（Task 指定素材）：模型为"52 岁王维"（13.4MB 静态），而场景年份开元二十四年（736）王维约 35 岁。剧本**不写年龄**，只用"半官半隐的王维"人设（辋川、诗画、佛理），并以"年过五十"仅出现在 AI 提示词中。答辩口径建议："模型为素材资产，人物设定以史实为准，剧本回避年龄表述。"
2. **王维无动画**：静态模型 `clips` 为空，`idle` 设 `loop: false`，只呈现站姿；无穿模风险，但动作表现力弱于其他 NPC。
3. **胡商/卖花女动画回退**：walking 模型的 `stateActions.path` 沿用储光羲写法填的是模型路径，HTML 用 `AnimationClip.findByName` 匹配不到会 `console.warn` 并回退 `clips[0]`，不影响显示；期望动作即为 walking。位置/朝向初值待 project-runner 实拍微调。
4. **卡片 `node_end` 用 `closeOnEnd` 而非 `showInput`**：与任务书"node_end 保留 showInput"的字面要求有一处有意偏差——卡片没有 `text_`，若显示输入框会向后端发送 `undefined` 提示词并报错。人物树 5 个 `node_end` 均保留 `showInput: true`。如后续给卡片补 `text_`，可统一改为 showInput。
5. **多行诗文的换行**：`text` 内用 `\n` 分行，但 `#popup-text` 未设 `white-space: pre-line` 时浏览器会折叠换行（v1 即如此）。若 `run\3Dprogram_3.1.html` 正在做对话 UI 改版，建议顺手加 `#popup-text{white-space:pre-line}`。
6. **v1 既有问题（未在本次范围内改动）**：岑参 `stateActions` 有两处路径拼写为 `.glbb`（`sit_floor_read`、`recite`）；`zero` 场景引用 `将军run.glb` 本机不存在。二者均为旧稿遗留，不影响本场景正常显示（stateActions.path 仅用于匹配动画名，模型由 `path` 加载）。
7. **卡片显示名与 key 不一致**（`gate`→过街门楼、`ta`→塔、`许多灯笼商铺2`→许多灯笼商铺）为 v1 原有展示名，未改；不影响交互。
